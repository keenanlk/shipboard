Netlify

Netlify deploy status in your Mac menu bar

ShipBoard shows the latest Netlify deploy for each site and context — Production, Deploy Preview and Branch Deploys — in the macOS menu bar, and sends a native notification the moment a deploy fails.

Download ShipBoard — Free macOS 14+ · Apple Silicon & Intel · v1.1.1

What you see for each deploy context

  • The newest deploy for each context you add, split into Build and Deploy steps.
  • The deploy’s branch and title (usually the commit message).
  • Open deployment on Netlify to jump to that deploy.
  • Green when ready; red on error or rejected; amber while building or processing; grey when skipped or cancelled.

Set it up

  1. Create a personal access token under User settings → Applications, and give it an expiration date.
  2. In ShipBoard, click +, choose Netlify, and paste the token. It’s verified with Netlify, then saved to your Keychain.
  3. Search your sites and tick the deploy contexts to watch.

What access ShipBoard needs

CredentialA Netlify personal access token, stored in the macOS Keychain.
ScopeNetlify personal access tokens have no scopes — they act as your account. ShipBoard only makes read requests.
API callsGET /api/v1/user, /api/v1/sites, /api/v1/sites/{id}/deploys

ShipBoard never triggers, locks or deletes deploys. An expiring token limits the damage if your Mac is ever compromised.

Good to know

  • Contexts are Production, Deploy Preview and Branch Deploys; individual branches can’t be picked yet.
  • ShipBoard looks at each site’s 30 most recent deploys, so a context that hasn’t deployed recently shows grey.
  • The picker lists up to 100 sites.

Netlify FAQ

Why does Netlify need a full-access token?

Netlify personal access tokens don’t have scopes. ShipBoard only sends GET requests, and the token stays in your Keychain.

Can I watch deploy previews?

Yes. Pick Production, Deploy Preview and Branch Deploys per site.

Does it work with SSO teams?

Netlify blocks personal access tokens for SAML SSO teams unless you allow it when creating the token.

Will it tell me when a deploy fails?

Yes. macOS shows a native notification when a deploy goes from building to failed, and optionally when it succeeds. You can turn each one off in Settings.

How often does ShipBoard check Netlify?

Every 30 seconds by default; you can choose anything from 15 seconds to 5 minutes in Settings. Each check makes one read-only request per site, which covers all of its deploy contexts, and if Netlify can’t be reached ShipBoard retries every 15 seconds until it’s back.

What happens when my token expires?

The Netlify group on the board shows “Your Netlify token is invalid or expired.” Netlify also invalidates personal access tokens when you reset your password. Use Set Netlify token on that row to paste a new one.
